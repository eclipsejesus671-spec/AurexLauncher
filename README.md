# Aurex Launcher — Android starter

This is a native Android Jetpack Compose starter for a black-and-gold Minecraft launcher UI with blue accent branding.

## Open and build
1. Download and extract the ZIP.
2. Open the `AurexLauncher` folder in Android Studio.
3. Let Gradle sync.
4. Build > Build APK(s).

## Important limitation
This project currently implements the UI and navigation prototype only. The Launch button does **not** launch Minecraft yet. A real Minecraft Java launcher requires integrating a compatible Android launcher backend, Java runtimes, game/library downloads, account authentication, renderer support, and appropriate licensing. This starter deliberately does not claim those features already work.

The project is independently branded and does not include MJ/Pojav source code or assets.
